    A save editor for the Pokémon Z fangame: open a save file to view and edit your trainer, party, boxes, bag, and every variable and switch the game tracks — level up a Pokémon, fix its IVs, add items, and more — then download the edited file and copy it back over your real save.

    Which species this save has seen and owned. Marking a species seen or owned here only changes the Pokédex record, not what you actually have.
